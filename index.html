Joint-Embedding Predictive Architecture · for Language Models

Predicting meaning, not just words,
over scientific reasoning chains

An empirical study of JEPA objectives for language models. We add an embedding-space prediction loss on top of next-token prediction and ask one honest question: does it make a stronger generative model?

See the demo ↓ Run it yourself

The core idea

A normal model predicts the exact next word. JEPA predicts the embedding — the meaning vector — of what comes next. We combine both so the model learns meaning without the embeddings collapsing to garbage.

🔤

Next-token (NTP)

The standard objective. Predict each next token. Keeps embeddings informative and prevents collapse.

🧭

JEPA

Predict the embedding of a later reasoning stage from earlier ones. Learning in meaning-space, not surface text.

⚖️

Combined loss

We weight the two with $\lambda$. The whole study asks how this weight changes generative quality.

$$\mathcal{L} \;=\; \underbrace{\mathcal{L}_{\text{NTP}}}_{\text{predict words}} \;+\; \lambda\cdot \underbrace{\mathcal{L}_{\text{JEPA}}}_{\text{predict meaning}}$$

The pipeline

Every paper is decomposed into a 6-stage reasoning chain. JEPA learns to predict the embedding of a later stage from earlier ones — including a long-range method → result edge that probes real reasoning.

Objective A

Next-token (NTP)

Predict each next token. Anchors the model to real language and keeps embeddings informative.

Objective B

JEPA — predict the embedding

For each edge $(i,j)$, predict the embedding of stage $j$ from stages $0..i$, maximizing cosine similarity.

$$\boxed{\;\mathcal{L} \;=\; \mathcal{L}_{\text{NTP}} \;+\; \lambda\cdot \frac{1}{|E'|}\sum_{(i,j)\in E'}\bigl(1-\cos(\hat z_{ij},\,z_j)\bigr)\;}$$

How it works & why it should help?

Below: precise definitions, then the mechanistic arguments for why an embedding-prediction term could beat next-token alone. The arguments are intuitions/hypotheses; the λ-sweep is the actual evidence.

1 · Setup & notation

A chain is a sequence of stages $s_0,\dots,s_5$. A shared encoder $f_\theta$ maps any stage's tokens to a vector. We define: $$z_j = f_\theta(s_j)\in\mathbb{R}^d \quad\text{(target embedding of stage } j)$$ $$\hat z_{ij} = g_\theta\bigl(f_\theta(s_{0:i})\bigr)\in\mathbb{R}^d \quad\text{(prediction of stage } j \text{ from context } 0..i)$$ where $g_\theta$ is the predictor (read out from the [PRED] tokens). Edges $E=\{(0,1),(1,2),(2,3),(3,4),(4,5),(2,4)\}$ say which $j$ we predict from which $i$.

3 · The JEPA term (predict meaning, not words)

For each kept edge we maximize cosine similarity between prediction and target: $$\ell_{ij}=1-\cos(\hat z_{ij},z_j)=1-\frac{\hat z_{ij}^{\top}z_j}{\lVert\hat z_{ij}\rVert\,\lVert z_j\rVert}$$ Averaging over the surviving edges $E'\subseteq E$ (loss dropout removes some): $$\mathcal{L}_{\text{JEPA}}=\frac{1}{|E'|}\sum_{(i,j)\in E'}\ell_{ij}$$ Each edge $i\!\to\!j$ at distance $j-i$ asks the model to anticipate a later stage's meaning — the $(2,4)$ edge being the hardest (method ⇒ result).

4 · The combined objective & its gradient

$$\mathcal{L}=\mathcal{L}_{\text{NTP}}+\lambda\,\mathcal{L}_{\text{JEPA}}, \qquad \nabla_\theta\mathcal{L}=\nabla_\theta\mathcal{L}_{\text{NTP}}+\lambda\,\nabla_\theta\mathcal{L}_{\text{JEPA}}$$ The JEPA gradient injects an extra learning signal at every step. Whether this helps depends on $\lambda$ — too small and it's negligible; too large and it overwhelms the language signal. Hence the U-shaped sweep.

Why it should help — four mechanisms

Hypothesis · not proof

① A denser learning signal

NTP gives one signal per token. JEPA adds a signal per edge, in a low-dimensional meaning space. Heuristically the effective signal per step grows: $$\text{signal} \;\propto\; \underbrace{T}_{\text{tokens}} \;+\; \lambda\,\underbrace{|E'|}_{\text{edges}}$$ More informative gradient per example ⇒ faster, more data-efficient learning.
Hypothesis · not proof

② Smoother targets (denoising)

Predicting exact tokens forces the model to model surface noise (synonyms, phrasing). Predicting an embedding targets an averaged meaning: $$z_j=f_\theta(s_j)\ \text{discards token-level entropy}.$$ Lower-entropy targets ⇒ lower-variance gradients ⇒ more stable optimization. This is the classic argument for predictive representation learning (cf. masked/contrastive methods).
Hypothesis · not proof

③ Long-range structure

The $(2,4)$ edge forces $\hat z_{24}\!\approx\! z_4$: the model must encode enough of the method to anticipate the result. This pressures the representation to capture causal/scientific structure that token-local NTP need not learn, which can transfer back into better next-token prediction.
Why collapse won't happen

④ NTP prevents collapse

JEPA alone has a trivial minimizer: a constant encoder $f_\theta(\cdot)=c$ gives $\cos=1,\ \mathcal{L}_{\text{JEPA}}=0$ — useless embeddings. But that same $c$ makes $\mathcal{L}_{\text{NTP}}$ maximal (the model can't predict words). The joint loss has no constant minimizer: $$\arg\min_\theta\bigl(\mathcal{L}_{\text{NTP}}+\lambda\mathcal{L}_{\text{JEPA}}\bigr)\neq\{\text{constant }f_\theta\}.$$ So NTP is the anti-collapse anchor that lets JEPA add value safely.
The falsifiable prediction. If these mechanisms are real, there exists $\lambda^\star>0$ with $\mathrm{PPL}(\lambda^\star)<\mathrm{PPL}(0)$, and the improvement is statistically significant across seeds (paired $t$-test, Holm–Bonferroni). If no $\lambda>0$ beats $\lambda=0$, the hypothesis is rejected — and that is still a valid, reportable result. The math motivates; the sweep decides.

Run it yourself

You only ever run experiments.py. Always smoke-test first.

1 · Setup & smoke test

pip install -r requirements.txt

# ~2 min - catches errors before you scale
python experiments.py --study all --smoke

2 · Real Phase-1 studies

# fine-tuning (from_scratch = False)
python experiments.py --study lambda   --tier P1 --seeds 3
python experiments.py --study ablation --tier P1 --seeds 3
python experiments.py --study dropout  --tier P1 --seeds 3
